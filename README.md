# lbmlabs.org

The website for LBM Labs — a public-good lab. Flagship project:
[Mycelium](https://github.com/ConorMcCaulley/Mycelium-Network), a
free, open, encrypted environmental telemetry mesh.

Concept and launch plan live in the Mycelium repo under
`docs/website-concept.md` and `docs/website-launch-plan.md`.

## Status

Pre-launch scaffold. The hero animation prototype lives at
[`public/prototypes/mycelium-hero.html`](public/prototypes/mycelium-hero.html)
— a self-contained page, no build needed: open it directly or via the
deployed preview.

## Develop

```bash
npm install
npm run dev
```

Pushes to `main` deploy automatically to the GitHub Pages preview.
